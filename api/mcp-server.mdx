Nushir exposes an MCP (Model Context Protocol) server that lets any MCP-compatible AI assistant — Claude, GPT, Cursor, or your own agent — schedule posts, list channels, and pull analytics by calling Nushir tools directly. Instead of writing API integration code yourself, you configure your AI client once and then instruct it in natural language: "Schedule a post to Instagram for Monday at 9 AM announcing our v2.0 launch."

## Connection Details

| Property | Value |
|---|---|
| **MCP Server URL** | `https://mcp.nushir.com/v1` |
| **Authentication** | Bearer token (your Nushir API key) |
| **Protocol** | Model Context Protocol (MCP) over HTTPS |

Your Nushir API key is passed as the `Authorization: Bearer` header inside your MCP client's configuration. You can generate or copy your API key from **Settings → API → Keys**.

## Available Tools

Once connected, your AI agent has access to the following Nushir tools:

| Tool name | Description |
|---|---|
| `create_post` | Schedule a post to one or more connected channels at a specified time. |
| `list_posts` | Retrieve upcoming scheduled posts, optionally filtered by status or channel. |
| `list_channels` | List all channels connected to your Nushir account, with their IDs and statuses. |
| `get_analytics` | Fetch engagement metrics (reach, impressions, clicks) for a channel or individual post. |
| `create_draft_from_brief` | Send a content brief and receive a Writer-generated draft back for review. |

<Tip>
  Use `create_draft_from_brief` to hand off a rough idea or content brief to the Nushir Writer agent. Your AI assistant sends the brief, Nushir generates a polished draft, and you review it before it goes live — a fully AI-assisted content pipeline with a human checkpoint.
</Tip>

## Connecting Claude Desktop

Add a `nushir` entry to your Claude Desktop MCP server configuration file. On macOS this file lives at `~/Library/Application Support/Claude/claude_desktop_config.json`.

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "nushir": {
      "url": "https://mcp.nushir.com/v1",
      "headers": {
        "Authorization": "Bearer nushir_live_xxxx"
      }
    }
  }
}
```

Replace `nushir_live_xxxx` with your actual API key. Restart Claude Desktop after saving the file — Nushir will appear in your available tools list.

## Connecting Other MCP Clients

Any client that supports the Model Context Protocol can connect to Nushir by pointing to `https://mcp.nushir.com/v1` and adding your API key as a Bearer token header. Refer to your client's documentation for the exact configuration format — the pattern is identical to the Claude Desktop example above.

## Example: Asking Claude to Schedule a Post

Here is a typical end-to-end interaction once your MCP connection is live:

<Steps>
  <Step title="You give Claude a natural-language instruction">
    > "Schedule a post to our Instagram and X channels for September 1st at 9 AM announcing the v2.0 launch. Keep it punchy."
  </Step>
  <Step title="Claude calls the Nushir MCP tool">
    Claude selects the `create_post` tool and passes the relevant parameters — channel identifiers, scheduled time, and your brief — to the Nushir MCP server.
  </Step>
  <Step title="Nushir creates a draft">
    Nushir receives the tool call, generates or stores the post content, and returns a draft object with a post ID and a link to review the draft in the Nushir dashboard.
  </Step>
  <Step title="You review and approve">
    Claude surfaces the draft link in your conversation. You open it, review the copy, and approve or edit before it publishes.
  </Step>
</Steps>

<Note>
  MCP publishing always respects your channel approval settings. When you call `create_post` or `create_draft_from_brief` through the MCP server, Nushir creates a **draft** — it does not auto-publish. Posts only publish automatically if you have the auto-publish setting explicitly enabled for that channel in **Settings → Channels**.
</Note>

## Troubleshooting

<Accordion title="My MCP client says it can't reach the server">
  Confirm that `https://mcp.nushir.com/v1` is accessible from your network and that your API key is valid. You can test connectivity with:

  ```bash title="Test MCP server reachability"
  curl -I https://mcp.nushir.com/v1 \
    -H "Authorization: Bearer nushir_live_xxxx"
  ```

  A `200 OK` or `405 Method Not Allowed` response confirms the server is reachable and your key is accepted.
</Accordion>

<Accordion title="Claude isn't showing Nushir in its tools list">
  After editing `claude_desktop_config.json`, you must fully quit and relaunch Claude Desktop (not just close the window). Check that the JSON in the config file is valid — a stray comma or missing bracket will silently prevent the config from loading.
</Accordion>

<Accordion title="Tool calls succeed but posts don't appear in my dashboard">
  Verify that the API key in your MCP config belongs to the correct Nushir workspace. If you have multiple workspaces, keys are workspace-scoped — a key from Workspace A will not create posts in Workspace B.
</Accordion>
