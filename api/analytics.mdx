The Analytics API gives you structured access to performance data across your channels and individual posts. Use aggregate metrics to understand overall trends, or drill down to a specific post to see exactly how it performed. You can filter by channel, date range, and granularity to shape the data to your reporting needs.

---

## GET /v1/analytics

Retrieve aggregate analytics across your connected channels. Results are grouped by the `granularity` you specify and filtered by any channel or date parameters you provide.

### Query parameters

<ParamField query="channel_id" type="string">
  Filter results to a single channel. Omit to aggregate data across all channels.
</ParamField>

<ParamField query="from" type="string">
  ISO 8601 UTC datetime. Include data at or after this point in time (e.g. `2025-08-01T00:00:00Z`).
</ParamField>

<ParamField query="to" type="string">
  ISO 8601 UTC datetime. Include data up to and including this point in time (e.g. `2025-08-31T23:59:59Z`).
</ParamField>

<ParamField query="granularity" type="string">
  How to group results over time. Accepted values: `"day"`, `"week"`, `"month"`. Default: `"day"`.
</ParamField>

### Response fields

<ResponseField name="period" type="object">
  The start and end datetimes of the aggregated period, in ISO 8601 format.
</ResponseField>

<ResponseField name="impressions" type="integer">
  Total number of times your posts were displayed to users during this period.
</ResponseField>

<ResponseField name="engagements" type="integer">
  Total number of engagement actions (likes, comments, shares, clicks) across all posts in the period.
</ResponseField>

<ResponseField name="engagement_rate" type="number">
  Engagements divided by impressions, expressed as a decimal (e.g. `0.042` = 4.2%).
</ResponseField>

<ResponseField name="top_posts" type="string[]">
  Array of post IDs ranked by total engagements in the period. Use these IDs with [GET /v1/analytics/posts/{id}](#get-v1analyticspostsid) for detailed breakdowns.
</ResponseField>

### Example

<CodeGroup>
```bash title="Request"
curl "https://api.nushir.com/v1/analytics?channel_id=ch_01abc123&from=2025-08-01T00:00:00Z&to=2025-08-31T23:59:59Z&granularity=week" \
  -H "Authorization: Bearer nushir_live_xxxx"
```

```json title="Response — 200 OK"
{
  "data": [
    {
      "period": {
        "start": "2025-08-01T00:00:00Z",
        "end": "2025-08-07T23:59:59Z"
      },
      "impressions": 42810,
      "engagements": 1893,
      "engagement_rate": 0.0442,
      "top_posts": ["post_9kLmN3pQ", "post_3aRvT8wY"]
    },
    {
      "period": {
        "start": "2025-08-08T00:00:00Z",
        "end": "2025-08-14T23:59:59Z"
      },
      "impressions": 38540,
      "engagements": 1621,
      "engagement_rate": 0.0421,
      "top_posts": ["post_7jKpR2mX", "post_1bNqW5sZ"]
    }
  ],
  "channel_id": "ch_01abc123",
  "granularity": "week"
}
```
</CodeGroup>

## GET /v1/analytics/posts/{id}

Retrieve detailed analytics for a single post. This endpoint returns a full breakdown of every engagement type Nushir tracks for that post across all channels it was published on.

### Response fields

<ResponseField name="impressions" type="integer">
  Number of times the post was displayed to users.
</ResponseField>

<ResponseField name="likes" type="integer">
  Total likes (or reactions) across all channels the post was published to.
</ResponseField>

<ResponseField name="comments" type="integer">
  Total comments received on the post.
</ResponseField>

<ResponseField name="shares" type="integer">
  Total shares, reposts, or retweets.
</ResponseField>

<ResponseField name="clicks" type="integer">
  Total link clicks within the post copy or attached cards.
</ResponseField>

<ResponseField name="reach" type="integer">
  Unique accounts that saw the post (distinct from impressions, which counts repeat views).
</ResponseField>

### Example

<CodeGroup>
```bash title="Request"
curl https://api.nushir.com/v1/analytics/posts/post_9kLmN3pQ \
  -H "Authorization: Bearer nushir_live_xxxx"
```

```json title="Response — 200 OK"
{
  "post_id": "post_9kLmN3pQ",
  "impressions": 18430,
  "likes": 742,
  "comments": 89,
  "shares": 211,
  "clicks": 334,
  "reach": 15920
}
```
</CodeGroup>

<Note>
  Analytics data is refreshed every **4 hours**. Real-time metrics are not available via the API. If you need the most current figures for a post, check the Nushir dashboard, which displays the latest synced data.
</Note>

<Tip>
  Combine the Analytics API with [Webhooks](/api/webhooks) to build your own reporting pipeline. Use webhooks to receive a notification when a post is published, then call `GET /v1/analytics/posts/{id}` on a schedule to backfill performance data into your own data warehouse or BI tool.
</Tip>
