| API identifier | `mastodon` |
| Account required | Any account on any instance. |
| Media | Optional. |
| Multi-part posts | Native thread. |
| Analytics | None. |

## Connecting

**Add Channel → Mastodon**, approve access on the platform, and you are returned
here. See [connect a channel](/general/channels/connect) for the general flow.

## Worth knowing

Character limits are set per instance, not globally — the composer uses the connected instance's limit.

## Posting over the API

Use `mastodon` as the channel's `identifier`. The `settings` object this platform
expects is listed in [channel settings](/public-api/channel-settings).
