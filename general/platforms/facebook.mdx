| | |
|---|---|
| API identifier | `facebook` |
| Account required | **A Page you administer.** Personal profiles cannot be published to. |
| Media | Optional. |
| Multi-part posts | Follow-up comments. |
| Analytics | Account and post metrics. |

## Connecting

**Add Channel → Facebook Page**, approve access on the platform, and you are returned
here. See [connect a channel](/general/channels/connect) for the general flow.

## Worth knowing

The most common failure is connecting an account that administers no page — the token is granted and publishing then fails.

## Posting over the API

Use `facebook` as the channel's `identifier`. The `settings` object this platform
expects is listed in [channel settings](/public-api/channel-settings).
