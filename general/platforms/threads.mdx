| | |
|---|---|
| API identifier | `threads` |
| Account required | Any Threads account. |
| Media | Optional. |
| Multi-part posts | Native thread. |
| Analytics | Post metrics only. |

## Connecting

**Add Channel → Threads**, approve access on the platform, and you are returned
here. See [connect a channel](/general/channels/connect) for the general flow.

## Worth knowing

Shares Meta's app configuration with Instagram but is a separate channel and a separate connection.

## Posting over the API

Use `threads` as the channel's `identifier`. The `settings` object this platform
expects is listed in [channel settings](/public-api/channel-settings).
