## Connecting

**Add Channel → X**, approve access on the platform, and you are returned
here. See [connect a channel](/general/channels/connect) for the general flow.

## Worth knowing

Free API tiers are heavily rate limited; posting frequently to one account can be throttled by X rather than by Nushir.

## Posting over the API

Use `x` as the channel's `identifier`. The `settings` object this platform
expects is listed in [channel settings](/public-api/channel-settings).
