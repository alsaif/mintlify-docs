| | |
|---|---|
| API identifier | `telegram` |
| Account required | The bot must be an administrator of the channel. |
| Media | Optional. |
| Multi-part posts | Follow-up messages. |
| Analytics | None. |

## Connecting

**Add Channel → Telegram**, approve access on the platform, and you are returned
here. See [connect a channel](/general/channels/connect) for the general flow.

## Worth knowing

Posts to a channel or group. Adding the bot without admin rights is the usual cause of a silent failure.

## Posting over the API

Use `telegram` as the channel's `identifier`. The `settings` object this platform
expects is listed in [channel settings](/public-api/channel-settings).
