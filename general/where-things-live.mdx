## The sidebar

| Section | What it is for |
|---|---|
| **Calendar** | The default view. Everything scheduled and published. |
| **Agent** | Conversational drafting, where enabled on your plan. |
| **Analytics** | Per-channel metrics, for platforms that report them. |
| **Media** | Everything you have uploaded, reusable across posts. |
| **Plugs** | Automatic follow-up actions on posts that perform. |
| **Integrations** | Third-party services that feed media into the composer. |
| **Settings** | Team, channels, API keys, billing. |

## The channels panel

Left of the calendar. Every connected channel, with **Add Channel** above it.

A channel with a warning marker needs reconnecting — usually the platform
expired or revoked the token. Nothing publishes to it until it is reconnected.

## Why a section might be missing

- **Plan.** Some features are limited by tier. See [plans](/cloud/plans).
- **Role.** Team members below admin do not see billing or API keys.
- **Configuration.** Features depending on a provider the deployment has not
  configured — video generation, for example — are hidden rather than shown
  broken.
