title: "Sets and signatures"
description: "Save a channel selection, and a sign-off you reuse on every post."
---

Two small features that remove the most repetitive parts of composing.

## Sets

A **set** is a saved channel selection. Posting to the same nine channels every
time? Save them once, and the composer selects all nine in one click.

Sets pair naturally with [client groups](/general/channels/customers): one set
per client, and a post for that client starts correctly targeted.

## Signatures

A **signature** is a saved block appended to the post body — a sign-off, a
disclaimer, a standing set of hashtags. Choose one in the composer and it is
added to the content before publishing.

Signatures count against each platform's character limit like any other text,
which is worth remembering on X-length platforms.
