## Redeeming

Promotional codes are entered at checkout or in billing settings. A valid code
shows its effect — percentage or fixed amount, and duration — before you
confirm.

## How discounts run

A discount applies from the next charge and for the period the code specifies.
When it lapses, billing returns to the plan's standard price; the change is
visible in billing settings ahead of the charge.

## The usual failures

- **Expired** — codes carry an end date.
- **Already used** — most codes are once per account.
- **Wrong plan** — some codes apply only to specific tiers.

The error at entry names which of these it was. Anything unclear:
[support](/general/support), with the code included.
