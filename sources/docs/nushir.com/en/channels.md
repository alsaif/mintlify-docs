## Missing a channel? Add it yourself

Anything with an API can join Nushir as a custom channel: your own app, an internal forum, or the screens in your store. Same calendar, same review flow.

REST API Webhooks MCP n8n Make

\# register a custom channel

POST /v1/channels

{ "type": "custom",

"name": "in-store screens",

"webhook": "https://…/publish" }

✓ channel ready · counts as 1 channel
