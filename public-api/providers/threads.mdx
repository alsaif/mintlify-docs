---
title: "Threads"
description: "Posting to `threads` channels - no settings object required."
---

Channels whose `identifier` is `threads` need no `settings` object: content and
media are the whole payload. Include the channel in `posts` and omit
`settings`, or send an empty object with `__type` set to `"threads"`.

Platform behaviour - media rules, thread handling, account requirements - is
covered in the [platform reference](/general/platforms/overview).
