Channels whose `identifier` is `instagram-standalone` validate the `settings` object below.
This page is generated from the application's own validation layer, so it
matches exactly what the server accepts.

Set `settings.__type` to `"instagram-standalone"`.

| Field | Type | Required | Notes |

| `label` | string | **required** |  |
| `id` | string | **required** |  |

| `image` | string | optional |  |
| `audio_volume` | number | optional |  |
| `video_volume` | enum | optional | Accepted: `post`, `story`. |
| `is_trial_reel` | object | optional |  |

| `collaborators` | array | optional |  |

<Note>
Settings are validated when a post is scheduled or published. Drafts skip this
validation entirely - see [errors](/public-api/errors) for how failures are
reported.
</Note>
