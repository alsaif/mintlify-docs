---
title: "Telegram"
description: "Posting to `telegram` channels - no settings object required."
---

Channels whose `identifier` is `telegram` need no `settings` object: content and
media are the whole payload. Include the channel in `posts` and omit
`settings`, or send an empty object with `__type` set to `"telegram"`.

Platform behaviour - media rules, thread handling, account requirements - is
covered in the [platform reference](/general/platforms/overview).
