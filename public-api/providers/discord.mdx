title: "Discord"
description: "The `settings` object for `discord` channels on POST /posts."
---

Channels whose `identifier` is `discord` validate the `settings` object below.
This page is generated from the application's own validation layer, so it
matches exactly what the server accepts.

Set `settings.__type` to `"discord"`.

## Fields

| Field | Type | Required | Notes |
|---|---|---|---|
| `channel` | string | **required** | Channel must be an id |

<Note>
Settings are validated when a post is scheduled or published. Drafts skip this
validation entirely - see [errors](/public-api/errors) for how failures are
reported.
</Note>
