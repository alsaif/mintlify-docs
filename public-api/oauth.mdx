The public REST API requires an organization API key. MCP OAuth tokens cannot
access its routes; sending one returns `401`. A token beginning with `pos_` does
not act as a REST API key.

For your own server integration, use the raw key header described in
[Authentication](/public-api/authentication).

## Delegated assistant connections

Assistants that support remote MCP with OAuth connect to:

```text
https://platform.nushir.com/api/mcp-oauth
```

The user signs in to Nushir and approves the application, workspace and displayed
permissions. MCP checks those permissions and the member's current workspace
role. Follow the [MCP connection guide](/mcp/introduction) for discovery,
authorization and supported tools; a REST client cannot substitute an MCP token
for its API key.

Users can revoke an assistant connection in **Settings → Approved Apps**.
If authorization expires or is revoked, follow the client's reconnection flow.
