---

تتطلب واجهة REST العامة مفتاح API للمنظمة. لا تستطيع رموز MCP مع OAuth
الوصول إلى مساراتها؛ وإرسال أحدها يعيد `401`. لا يعمل الرمز الذي يبدأ بـ
`pos_` كمفتاح لواجهة REST.

لتكامل الخادم الخاص بك، استخدم ترويسة المفتاح دون بادئة كما توضح صفحة
[المصادقة](/ar/public-api/authentication).

## اتصالات المساعد المفوَّضة

يتصل المساعد الذي يدعم MCP البعيد مع OAuth بالعنوان:

```text
https://platform.nushir.com/api/mcp-oauth
```

يسجّل المستخدم الدخول إلى Nushir ويوافق على التطبيق ومساحة العمل والأذونات
المعروضة. يتحقق MCP من هذه الأذونات ودور العضو الحالي في مساحة العمل. اتبع
[دليل الربط مع MCP](/ar/mcp/introduction) للاكتشاف والتفويض والأدوات المدعومة؛
لا يستطيع عميل REST استبدال مفتاح API برمز MCP.

يمكن للمستخدم إلغاء اتصال المساعد من **Settings → Approved Apps**.
عند انتهاء التفويض أو إلغائه، اتبع مسار إعادة الربط في العميل.
