title: "إعدادات القنوات"
description: "الكائن الخاص بكل منصة الذي يتطلبه POST /posts."
---

يمكن أن يحمل كل عنصر في `posts` كائن `settings`. ويعتمد ما ينتمي إليه على
`identifier` الخاص بالقناة، وهو **مطلوب** لعدة منصات — إغفاله يجعل الاستدعاء
يُرجع `400`.

<Note>
يمكن للمسودة حفظ `settings` غير مكتملة لبناء المنشور على مراحل. تبقى
الخيارات المحفوظة بحاجة إلى التحقق قبل الجدولة أو الاعتماد؛ حفظ المسودة
لا يعني أن إعداداتها جاهزة للنشر.
</Note>

## من أين تأتي البنية

إعدادات كل منصة يحددها مزوّدها داخل التطبيق، ولذلك تتبع هذه القائمة ما سيقبله
الخادم فعليًا. وعندما تغيّر منصة ما واجهة API الخاصة بها، تتغير الحقول
المقبولة معها.

## المنصات الشائعة

<AccordionGroup>
  <Accordion title="tiktok">
    يمكن بدء مسودة غير مكتملة بهذه القيم:

    ```json
    { "__type": "tiktok", "title": "مسودة للمراجعة" }
    ```

    هذا المثال غير مكتمل عمدًا. قبل الاعتماد أو الجدولة، أكمل إعدادات المزوّد
    داخل نُشر أو عبر مسار MCP المؤكّد لتحديث الإعدادات. اقرأ البنية الحالية
    بأداة Integration Schema وخيارات المنشئ الحالية بأداة `tiktokGetCreatorInfo`.

    | الحقل | الاختيار المطلوب للنشر المباشر |
    | --- | --- |
    | `content_posting_method` | اختر صراحةً `DIRECT_POST` للنشر أو `UPLOAD` لمسودة في صندوق وارد TikTok. |
    | `privacy_level` | اختر جمهورًا مسموحًا حاليًا للمنشئ دون تعيين مسبق. يقيّد نُشر النشر المباشر حاليًا بالرؤية «أنا فقط» أثناء مراجعة التطبيق. |
    | `comment` و`duet` و`stitch` | خيارات تفاعل منطقية بحسب أذونات المنشئ ونوع الوسائط. أسماء الحقول ليست `disable_*`. |
    | `autoAddMusic` | `yes` أو `no`؛ تنطبق الموسيقى التلقائية على الصور. |
    | `brand_organic_toggle` و`brand_content_toggle` و`disclose` | خيارات إفصاح تجاري دقيقة. لا يمكن للمحتوى ذي العلامة التجارية استخدام «أنا فقط». |
    | `posting_consent` | لا تكون `true` إلا بعد تفويض المستخدم صراحةً لهذا المنشور وطريقة إرساله. تتطلب الخيارات المتغيّرة موافقة جديدة. |

    يرسل `UPLOAD` المحتوى إلى صندوق وارد TikTok ليكمل المنشئ نشره، ولا يطبّق
    خصوصية النشر المباشر أو إعدادات التفاعل. لا تختره تلقائيًا لتجاوز طلب نشر
    مباشر غير مكتمل. راجع عناوين الصور ونصوص الفيديو داخل TikTok عندما تتطلب
    طريقة الإرسال المختارة ذلك.

    تعرض لوحة المراجعة الأصلية والحقل `settingsReadiness` في MCP الخيارات
    الناقصة أو غير الصالحة قبل الاعتماد. يبقي حفظ الإعدادات المنشور مسودة؛
    ويتحقق الاعتماد بشكل منفصل من الوسائط وموعد النشر المستقبلي.
  </Accordion>

  <Accordion title="reddit">
    ```json
    {
      "__type": "reddit",
      "subreddit": [{ "value": { "name": "r/example", "title": "Post title" } }]
    }
    ```

    تحديد subreddit مطلوب. ولكل subreddit قواعد نشر خاصة به، والمنشور الذي
    تقبله واجهة API قد يُزال مع ذلك من قِبل مشرفي ذلك الـ subreddit.
  </Accordion>

  <Accordion title="youtube">
    ```json
    {
      "__type": "youtube",
      "title": "Video title",
      "type": "public",
      "thumbnail": { "id": "med_01H9" }
    }
    ```

    العنوان مطلوب — فليس لدى YouTube مفهوم لرفع بلا عنوان.
  </Accordion>

  <Accordion title="instagram">
    ```json
    { "__type": "instagram", "post_type": "post", "collaborators": [] }
    ```

    يمكن أن تكون قيمة `post_type` هي `post` أو `reel` أو `story`. والوسائط
    مطلوبة في جميع الأحوال؛ فـ Instagram لا يقبل منشورًا نصيًا فقط.
  </Accordion>

    }

    تحديد اللوحة (board) مطلوب.

## معرفة البنية لأي منصة

طريقتان موثوقتان بدلًا من التخمين:

1. جهِّز منشورًا واحدًا من ذلك النوع في المحرِّر، ثم اقرأه عبر `GET /posts`
   وانسخ بنية `settings`.
2. يُرجع `GET /integration-settings/{id}` الإعدادات الافتراضية المخزَّنة
   للقناة.
