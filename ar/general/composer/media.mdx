أرفق الوسائط من المحرِّر، أو أعد استخدام أي عنصر موجود مسبقًا في
[مكتبة الوسائط](/ar/general/media-library).

## المتطلبات تختلف من منصة إلى أخرى

يفرض المحرِّر قواعد كل منصة قبل أن يسمح لك بالجدولة، ولهذا قد يُحظر على
Instagram منشور لا مشكلة فيه على X.

القاعدتان اللتان تفاجئان المستخدمين أكثر من غيرهما:

- **بعض المنصات لا تقبل منشورًا نصيًا فقط.** فكل من Instagram وTikTok
  تتطلبان وسائط.
- **نسبة الأبعاد والمدة تفرضهما المنصة نفسها**، لا نُشر. فقد يقبل المحرِّر
  مقطع فيديو ثم يُرفض عند النشر إذا خرج عمّا تسمح به المنصة.

راجع [مرجع المنصات](/ar/general/platforms/overview) للاطلاع على الجدول الخاص بكل منصة.

## الرفع عبر واجهة API

طريقتان، بحسب مكان الملف.

ملف محلي:

```bash
curl -X POST https://platform.nushir.com/api/public/v1/upload \
  -H "Authorization: $NUSHIR_API_KEY" \
  -F "file=@video.mp4"
```

إذا كان الملف متاحًا مسبقًا عبر عنوان URL عام — يجلبه الخادم مباشرة، فلا يمر
مقطع فيديو كبير عبر عمليتك إطلاقًا:

```bash
curl -X POST https://platform.nushir.com/api/public/v1/upload-from-url \
  -H "Authorization: $NUSHIR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/video.mp4"}'
```

تُعيد الطريقتان عنصر وسائط. أشِر إلى `id` الخاص به من داخل المنشور:

```json
{ "content": "Launch day.", "image": [{ "id": "med_01H9" }] }
```

<Note>
لا يرسل `upload-from-url` أي بيانات اعتماد مع طلب الجلب، لذا يجب أن يكون
عنوان URL قابلًا للوصول العام. عنوان URL موقَّع يفي بالغرض؛ أما مسار حاوية
تخزين خاصة فلا.
</Note>
