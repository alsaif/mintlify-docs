## الموحّد

متن واحد لجميع القنوات المحددة. عدِّله فتتحدَّث كل القنوات.

الخيار الأفضل عندما تكون الرسالة واحدة فعلًا وكل ما يهمك هو أن تصل إلى
كل مكان.

## لكل قناة

حوِّل قناة إلى محتوى خاص بها فتنفصل عن المسودة المشتركة، ولا يعود تعديل
النص الموحّد يؤثر فيها.

يستحق الأمر ذلك عندما:

- يفرض حد الأحرف في إحدى المنصات نسخة أقصر.
- تفيد الوسوم في منصة وتبدو في غير محلها في أخرى.
- ينبغي أن تحمل الرابط منصة واحدة فقط.

<Warning>
الفصل باتجاه واحد من الناحية العملية. فإعادة ربط القناة بالمسودة الموحّدة
تُلغي النسخة المخصَّصة — وسيسألك المحرِّر قبل تنفيذ ذلك.
</Warning>

## عبر واجهة API

لا تفرّق واجهة API بين المحتوى الموحّد والمحتوى لكل قناة. فكل عنصر في
`posts` يحمل مصفوفة `value` الخاصة به، لذا تُرسل النص النهائي لكل قناة:

```json
{
  "type": "schedule",
  "date": "2026-09-01T09:00:00Z",
  "posts": [
    {
      "integration": { "id": "CHANNEL_A" },
      "value": [{ "content": "The long version, for LinkedIn." }]
    },
    {
      "integration": { "id": "CHANNEL_B" },
      "value": [{ "content": "The short version." }]
    }
  ]
}
```
