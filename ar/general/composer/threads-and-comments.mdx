title: "السلاسل والتعليقات"
description: "المنشورات متعددة الأجزاء، وما تفعله كل منصة بها."
---

أضف جزءًا في المحرِّر فيصبح المنشور متعدد الأجزاء.

## ما تفعله كل منصة

| السلوك | المنصات |
|---|---|
| يُنشر كسلسلة أصلية على المنصة | X وBluesky وMastodon وThreads |
| يُنشر الجزء الأول، ثم البقية كتعليقات | معظم المنصات الأخرى |

في الحالتين تصل الأجزاء بالترتيب، ويعرض المحرِّر السلوك المطبَّق قبل أن
تُجدول المنشور.

## التأخير

يمكن أن يحمل الجزء تأخيرًا، حتى لا يصل التعليق اللاحق في الثانية نفسها
التي يصل فيها المنشور. وهذا مفيد حيث يبدو التعليق الذاتي الفوري وكأنه
آلي.

## عبر واجهة API

الأجزاء عناصر داخل `value`:

```json
{
  "integration": { "id": "CHANNEL_ID" },
  "value": [
    { "content": "The opening line." },
    { "content": "The follow-up." },
    { "content": "The link.", "delay": 300 }
  ]
}
```

يُقاس `delay` بالثواني ابتداءً من الجزء السابق.
