| | |
|---|---|
| معرّف API | `instagram` |
| الحساب المطلوب | **Business أو Creator**، مرتبط بصفحة فيسبوك. |
| الوسائط | **مطلوبة** — لا تُقبل المنشورات النصية فقط. |
| المنشورات متعددة الأجزاء | تعليقات متابعة. |
| التحليلات | مقاييس الحساب والمنشورات. |

## الربط

**"Add Channel" (إضافة قناة) → Instagram**، ثم وافق على منح الوصول في المنصة وستعود
إلى هنا. راجع [ربط قناة](/ar/general/channels/connect) للاطلاع على الخطوات العامة.

## جدير بالذكر

يحدد الحقل `post_type` نوع المحتوى: منشور (post) أو ريل (reel) أو قصة (story). يمكن ربط حساب شخصي لكنه لن يتمكن من النشر أبداً؛ حوّل نوع الحساب في تطبيق إنستغرام أولاً.

## النشر عبر API

استخدم `instagram` قيمةً للحقل `identifier` في القناة. كائن `settings` الذي تتوقعه
هذه المنصة موضح في [إعدادات القنوات](/ar/public-api/channel-settings).
