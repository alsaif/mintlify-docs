| معرِّف API | `mastodon` |
| الحساب المطلوب | أي حساب على أي خادم (Instance). |
| الوسائط | اختيارية. |
| المنشورات متعددة الأجزاء | سلسلة أصلية. |
| التحليلات | لا توجد. |

## الربط

**Add Channel → Mastodon** (إضافة قناة ← Mastodon)، ثم وافق على الوصول في المنصة،
وستعود إلى هنا. راجع [ربط قناة](/ar/general/channels/connect) للاطلاع على الخطوات العامة.

## جدير بالذكر

تُحدَّد حدود عدد الأحرف على مستوى كل خادم وليس عالميًا — يستخدم المحرِّر حد الخادم المتصل بحسابك.

## النشر عبر API

استخدم `mastodon` قيمةً لحقل `identifier` الخاص بالقناة. يمكنك الاطلاع على كائن `settings`
الذي تتوقعه هذه المنصة في [إعدادات القناة](/ar/public-api/channel-settings).
