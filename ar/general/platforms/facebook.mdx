---

| | |
|---|---|
| معرّف API | `facebook` |
| الحساب المطلوب | **صفحة تديرها.** لا يمكن النشر إلى الحسابات الشخصية. |
| الوسائط | اختيارية. |
| المنشورات متعددة الأجزاء | تعليقات متابعة. |
| التحليلات | مقاييس الحساب والمنشورات. |

## الربط

**"Add Channel" (إضافة قناة) → Facebook Page**، ثم وافق على منح الوصول في المنصة وستعود
إلى هنا. راجع [ربط قناة](/ar/general/channels/connect) للاطلاع على الخطوات العامة.

## جدير بالذكر

أكثر حالات الفشل شيوعاً هي ربط حساب لا يدير أي صفحة — فيُمنح رمز الوصول ثم يفشل النشر بعد ذلك.

## النشر عبر API

استخدم `facebook` قيمةً للحقل `identifier` في القناة. كائن `settings` الذي تتوقعه
هذه المنصة موضح في [إعدادات القنوات](/ar/public-api/channel-settings).
