| | |
|---|---|
| معرِّف API | `telegram` |
| الحساب المطلوب | يجب أن يكون البوت مشرفًا على القناة. |
| الوسائط | اختيارية. |
| المنشورات متعددة الأجزاء | رسائل متابعة. |
| التحليلات | لا توجد. |

## الربط

**Add Channel → Telegram** (إضافة قناة ← Telegram)، ثم وافق على الوصول في المنصة،
وستعود إلى هنا. راجع [ربط قناة](/ar/general/channels/connect) للاطلاع على الخطوات العامة.

## جدير بالذكر

ينشر إلى قناة أو مجموعة. إضافة البوت دون صلاحيات الإشراف هي السبب الأكثر شيوعًا للفشل الصامت.

## النشر عبر API

استخدم `telegram` قيمةً لحقل `identifier` الخاص بالقناة. يمكنك الاطلاع على كائن `settings`
الذي تتوقعه هذه المنصة في [إعدادات القناة](/ar/public-api/channel-settings).
