|---|---|
| معرِّف API | `discord` |
| الحساب المطلوب | يجب دعوة البوت إلى الخادم. |
| الوسائط | اختيارية. |
| المنشورات متعددة الأجزاء | رسائل متابعة. |
| التحليلات | لا توجد. |

## الربط

**Add Channel → Discord** (إضافة قناة ← Discord)، ثم وافق على الوصول في المنصة،
وستعود إلى هنا. راجع [ربط قناة](/ar/general/channels/connect) للاطلاع على الخطوات العامة.

## جدير بالذكر

ينشر إلى قناة داخل خادم، وليس إلى ملف شخصي.

## النشر عبر API

استخدم `discord` قيمةً لحقل `identifier` الخاص بالقناة. يمكنك الاطلاع على كائن `settings`
الذي تتوقعه هذه المنصة في [إعدادات القناة](/ar/public-api/channel-settings).
