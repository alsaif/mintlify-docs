مستويان: على مستوى القناة، وعلى مستوى المنشور.

## على مستوى القناة

المتابعون ومدى الوصول عبر الزمن، للمنصات التي تتيح واجهة API على مستوى الحساب.

## على مستوى المنشور

المشاهدات والإعجابات والتعليقات والمشاركات، حيثما تُبلغ عنها المنصة. ولا تكون
ذات معنى إلا بعد نشر المنشور.

## التغطية متفاوتة

هذا هو الجزء الجدير بالفهم: **ما تراه يعتمد كليًا على ما تتيحه كل منصة.**
فنُشر يفضِّل ألا يعرض شيئًا على أن يقدِّم تقديرات.

| الإبلاغ | المنصات |
|---|---|
| مقاييس الحساب والمنشورات | Instagram, TikTok, LinkedIn, Facebook, YouTube, Pinterest |
| محدودة أو للمنشورات فقط | X, Threads, Reddit |
| لا شيء | معظم منصات المحادثة والتدوين |

المنصة التي لا تُبلغ عن شيء تُرجع نتيجة فارغة، لا خطأً.

## التوقيت

تملأ المنصات المقاييس وفق جداولها الخاصة — عادة في غضون يوم، ويكاد ذلك لا
يكون فوريًا أبدًا. فالنتيجة الفارغة بعد ساعة من النشر أمر طبيعي.

## عبر واجهة API

```bash
# per channel
curl https://platform.nushir.com/api/public/v1/analytics/CHANNEL_ID \
  -H "Authorization: $NUSHIR_API_KEY"

# per post
curl https://platform.nushir.com/api/public/v1/analytics/post/POST_ID \
  -H "Authorization: $NUSHIR_API_KEY"
```
