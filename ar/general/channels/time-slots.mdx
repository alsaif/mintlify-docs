---
title: "أوقات النشر"
description: "حدّد الأوقات التي تنشر فيها القناة عادةً، وما الذي يعتمد عليها."
---

تحمل كل قناة قائمة بالأوقات التي تنشر فيها عادةً. وتُستخدم هذه الأوقات
لأمرين:

1. **Find a slot** (البحث عن موعد نشر) يعيد موعد النشر الحر التالي.
2. يقترحها التقويم عند النقر على منطقة فارغة.

هذه الأوقات اقتراحات لا قيود — يمكنك دائمًا جدولة منشور في أي وقت تريده.

## ضبط الأوقات

قائمة القناة ← **Preview** (معاينة)، ثم عدّل الأوقات. وهي تتكرر أسبوعيًا.

## لماذا يهم كون الموعد «حرًا»

يكون موعد النشر حرًا إذا لم يكن هناك شيء مجدول بالفعل لتلك القناة في ذلك
الوقت. طلب موعد النشر الحر التالي بشكل متكرر يمنحك قائمة انتظار موزّعة
بدلًا من خمسة منشورات متكدّسة في صباح واحد.

تتيح واجهة API المنطق نفسه:

```bash
curl https://platform.nushir.com/api/public/v1/find-slot/CHANNEL_ID \
  -H "Authorization: $NUSHIR_API_KEY"
```

```json
{ "date": "2026-09-02T09:00:00Z" }
```

<Note>
تُخزَّن الأوقات وتُعاد بتوقيت **UTC**. موعد النشر الذي يظهر بوصفه 09:00 في
حساب على توقيت UTC+3 يكون `06:00:00Z` عبر واجهة API.
</Note>
