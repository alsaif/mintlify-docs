Slack is where your team or community already lives, and Nushir makes it easy to keep those channels consistently updated without anyone having to babysit a posting schedule. Connect your workspace once, and the agent drafts messages up to 40,000 characters, supports rich attachments and Block Kit blocks, and can target multiple channels from a single connection — all subject to your review before anything posts.

## Channel Specs

| Property | Detail |
|---|---|
| **Content types** | Channel messages |
| **Text limit** | 40,000 characters |
| **Media** | Attachments and Block Kit blocks |
| **Platform features** | Multiple channels |

## What the Agent Does

<Steps>
  <Step title="Plans your rhythm">
    The agent figures out how frequently each Slack channel should receive posts and maps your content topics across those slots so the schedule feels intentional, not noisy.
  </Step>
  <Step title="Writes within platform limits">
    Your message is shaped for Slack — up to 40,000 characters — in your brand voice, using Slack's text formatting and Block Kit where appropriate.
  </Step>
  <Step title="Prepares media">
    File attachments and Block Kit blocks are prepared on-brand, pulling from your media library first and generating assets with AI when needed.
  </Step>
  <Step title="Reads the results">
    Post engagement and reaction data from Slack feeds back into the next planning cycle, so the agent learns which content and timing work best for your audience.
  </Step>
</Steps>

## How to Connect

<Steps>
  <Step title="Add the channel">
    Go to **Settings → Channels → Add Channel** and select **Slack**. You'll see all requested permissions before you approve.
  </Step>
  <Step title="Authenticate via Slack">
    Complete the Slack OAuth flow. Nushir is installed as a bot in your workspace with only the scopes required for posting.
  </Step>
  <Step title="Set your tone and target channels">
    Define the brand voice and restrictions for this connection, and specify which Slack channels the agent should post to.
  </Step>
  <Step title="Review drafts in the calendar">
    All drafts appear in your Nushir content calendar. Approve, edit, or reschedule before they publish.
  </Step>
</Steps>

<Tip>
  Slack's 40,000-character limit makes it a great destination for longer-form updates — internal release notes, weekly digests, or detailed how-to messages that wouldn't fit on other channels.
</Tip>

## FAQ

<AccordionGroup>
  <Accordion title="Will Nushir post without my approval?">
    No. Every message is a draft by default. Enable auto-publish for this Slack connection in settings if you want the agent to post without a manual review step.
  </Accordion>
  <Accordion title="Can I post to multiple Slack channels from one connection?">
    Yes. A single connected Slack workspace counts as one channel slot, and within it you can configure the agent to target as many channels as you like.
  </Accordion>
  <Accordion title="Does the agent support Block Kit?">
    Yes. When you enable rich formatting, the Writer agent can structure messages using Slack's Block Kit — buttons, sections, images, and dividers.
  </Accordion>
  <Accordion title="How does this count against my plan?">
    Each connected Slack workspace uses one channel slot. Check the [pricing page](https://nushir.com/pricing.html) for the number of slots available on your plan.
  </Accordion>
  <Accordion title="Can I publish via API or MCP?">
    Yes. You can post to Slack programmatically using the Nushir REST API or via MCP from your own agent or workflow tool.
  </Accordion>
</AccordionGroup>
