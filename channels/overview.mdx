Nushir's AI publishing agent doesn't spray the same text across every tab. It understands that a LinkedIn reader expects a narrative, an X follower wants a punchy 280-character take, and a TikTok viewer needs a 15-second script — not a caption. Connect as many channels as your plan allows, and the agent handles formatting, character limits, media sizing, and posting rhythm for each one independently. Every draft lands in your calendar for review before anything goes live.

<Note>
  Each connected account counts as **one channel slot** in your plan. Two Instagram accounts = two channels. Check [Nushir pricing](https://nushir.com/pricing.html) to see how many channels your plan includes.
</Note>

## Custom Channel {#custom-channel}

Any platform that exposes an API can be connected to Nushir as a custom channel. That includes your own mobile app, an internal company portal, digital signage in your office, or any third-party tool not already listed above. The agent treats a custom channel exactly like a native one — drafts appear in the calendar, you approve, and Nushir delivers to your endpoint.

Custom channels are registered with a single API call and support four integration methods:

| Method | Best for |
|---|---|
| **REST API** | Direct HTTP `POST` on publish |
| **Webhooks** | Event-driven push to your own server |
| **MCP** | Model Context Protocol for agent-to-agent publishing |
| **n8n / Make** | No-code workflow automation |

```json
// Register a custom channel
POST /v1/channels
{
  "type": "custom",
  "name": "in-store screens",
  "webhook": "https://your-domain.com/publish"
}

// Response
{ "status": "channel ready", "counts_as": 1 }
```

<Tip>
  Custom channels follow the same draft-first workflow as every native channel. Nothing posts to your endpoint until you approve the draft in the calendar.
</Tip>
