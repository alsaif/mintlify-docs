Discord communities thrive on consistent, well-timed communication, and keeping that up manually is a real time sink. Connect your server once, and Nushir's agent plans your posting rhythm, writes channel messages and announcements up to 2,000 characters, bundles multiple attachments, and supports role mentions — then waits in your calendar for your approval before anything posts.

## Channel Specs

| Property | Detail |
|---|---|
| **Content types** | Channel messages, announcements |
| **Text limit** | 2,000 characters |
| **Media** | Multiple attachments |
| **Platform features** | Role mentions |

## What the Agent Does

<Steps>
  <Step title="Plans your rhythm">
    The agent calculates a sustainable posting cadence for your Discord server — enough to keep your community engaged without flooding every channel — and maps your topics across the schedule.
  </Step>
  <Step title="Writes within platform limits">
    Your idea is shaped into a Discord message of up to 2,000 characters, in your brand voice, with appropriate role mentions where relevant.
  </Step>
  <Step title="Prepares media">
    Multiple attachments are assembled on-brand, sourced from your media library first, and generated by AI when nothing in the library fits.
  </Step>
  <Step title="Reads the results">
    Engagement data from your Discord channels feeds back into the next planning cycle, helping the agent refine timing and topic selection.
  </Step>
</Steps>

## How to Connect

<Steps>
  <Step title="Add the channel">
    Go to **Settings → Channels → Add Channel** and select **Discord**. The permissions screen shows exactly what Nushir will be able to do before you confirm.
  </Step>
  <Step title="Authenticate and select your server">
    Complete the Discord OAuth flow and choose which server — and which channels — Nushir should have access to.
  </Step>
  <Step title="Set your tone and restrictions">
    Configure the brand voice, off-limits topics, and preferred role mentions for this channel.
  </Step>
  <Step title="Review drafts in the calendar">
    Drafts appear in your content calendar. Approve, edit, or reschedule each post before it goes live.
  </Step>
</Steps>

<Note>
  You can revoke Nushir's access to your Discord server at any time from Nushir's channel settings or directly from your Discord server's **Authorized Apps** page.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="Will Nushir post without my approval?">
    No. The default mode is **draft** — every message waits in your calendar for sign-off. You can enable auto-publish for this channel in settings if you prefer a fully automated flow.
  </Accordion>
  <Accordion title="Can the agent post to multiple Discord channels?">
    Yes. During setup you select which channels within your server the agent can post to. Each connected Discord server counts as one channel slot, and the agent manages posting across all the channels you've enabled within it.
  </Accordion>
  <Accordion title="Does the agent support announcement channels?">
    Yes. The agent can target Discord announcement channels and will format messages appropriately so they can be cross-posted to other servers that follow yours.
  </Accordion>
  <Accordion title="How does this count against my plan?">
    Each connected Discord server uses one channel slot. See the [pricing page](https://nushir.com/pricing.html) for how many slots your plan includes.
  </Accordion>
  <Accordion title="Can I publish via API or MCP?">
    Yes. The Nushir REST API and MCP both support publishing to Discord, so you can trigger posts from your own agent or automation pipeline.
  </Accordion>
</AccordionGroup>
