If your platform has an API or accepts webhook payloads, you can connect it as a custom channel — your internal app, in-store screens, a proprietary CMS, or any service not in the built-in list. Custom channels get the same AI-powered planning, writing, and scheduling as every other Nushir channel. The only difference is where the post goes when it's published.

## How It Works

When Nushir publishes a post to a custom channel, it sends an **HTTP POST** to your webhook URL with the post payload. Your endpoint receives the content — text, media URLs, and metadata — and handles delivery however your system requires. You can point that webhook at your own backend, an automation platform like n8n or Make, or any service that can accept an HTTP request.

<Note>
  Custom channels count as **one channel slot** in your plan, exactly like any built-in channel. See the [pricing page](https://nushir.com/pricing.html) for how many slots your plan includes.
</Note>

## How to Add a Custom Channel

<Steps>
  <Step title="Open the Add Channel flow">
    Go to **Settings → Channels → Add Channel** and select **Custom**.
  </Step>
  <Step title="Give it a name">
    Enter a descriptive name so you can identify it in the calendar — for example, `In-Store Screens` or `Internal Announcements CMS`.
  </Step>
  <Step title="Paste your webhook URL">
    Enter the full HTTPS URL of the endpoint that should receive the post payload.
  </Step>
  <Step title="Add an auth header (optional)">
    If your endpoint requires authentication, add the header name and value — for example, `Authorization: Bearer <your-token>`. Nushir sends this header with every request.
  </Step>
  <Step title="Save and start scheduling">
    Click **Save**. The channel is immediately available in your content calendar, and the agent can start drafting posts for it.
  </Step>
</Steps>

## Webhook Payload

Every time Nushir publishes to a custom channel, your endpoint receives a JSON body with the following structure:

```json
{
  "channel_id": "ch_abc123",
  "post_id": "post_xyz789",
  "scheduled_at": "2026-09-01T09:00:00Z",
  "text": "Launching v2.0 today.",
  "media": [
    { "type": "image", "url": "https://media.nushir.com/..." }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `channel_id` | string | The unique ID of this custom channel in Nushir |
| `post_id` | string | The unique ID of the post being published |
| `scheduled_at` | ISO 8601 string | The time the post was scheduled to publish |
| `text` | string | The post body copy |
| `media` | array | Zero or more media objects, each with a `type` and a CDN `url` |

<Tip>
  Use **n8n** or **Make** to route custom channel webhooks to multiple destinations simultaneously — for example, posting the same content to your in-store screens and your internal Notion database in a single step.
</Tip>

## API Alternative

You can also register a custom channel programmatically using the Nushir REST API:

```bash
POST /v1/channels
Content-Type: application/json
Authorization: Bearer <your-api-key>

{
  "type": "custom",
  "name": "In-Store Screens",
  "webhook": "https://your-domain.com/publish"
}
```

A successful response returns the new `channel_id` you can reference in subsequent API calls to schedule and publish posts.

## FAQ

<AccordionGroup>
  <Accordion title="Does my endpoint need to respond in a specific way?">
    Your endpoint should return a `2xx` HTTP status code to confirm successful receipt. If Nushir receives a non-2xx response, the delivery is marked as failed and surfaced in the channel's error log so you can retry.
  </Accordion>
  <Accordion title="Can I use a custom channel with auto-publish?">
    Yes. Custom channels support the same draft and auto-publish modes as built-in channels. Enable auto-publish in the channel settings to have Nushir deliver posts to your webhook at the scheduled time without manual approval.
  </Accordion>
  <Accordion title="Is HTTPS required for the webhook URL?">
    Yes. Nushir only sends payloads to HTTPS endpoints to keep your content in transit secure.
  </Accordion>
  <Accordion title="Can I add more than one custom channel?">
    Yes. Each custom channel is a separate entry with its own name, webhook URL, and channel slot. Add as many as your plan allows.
  </Accordion>
  <Accordion title="Can I test the webhook before going live?">
    You can use a service like Webhook.site or a local tunnel (e.g., ngrok) to inspect the payload format before pointing Nushir at your production endpoint. Once you're satisfied, update the webhook URL in the channel settings.
  </Accordion>
  <Accordion title="Can I publish to a custom channel via the API or MCP?">
    Yes. The Nushir REST API and MCP both support targeting custom channels by `channel_id`, so you can trigger post delivery from your own agent or pipeline.
  </Accordion>
</AccordionGroup>
